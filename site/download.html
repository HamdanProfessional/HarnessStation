Get HarnessStation

Free and open source, for Windows and Linux. Or skip the install entirely and run the full app in your browser — same features, nothing to set up.

Local-first. No account. No telemetry. Your keys stay in your OS keychain. Your chats never leave your machine.

Windows

Windows 10 or 11 (64-bit). Choose the .exe installer or the .msi package.

The installer isn't code-signed yet, so Windows SmartScreen will warn on first run — click More info → Run anyway.

Download for Windows

Linux

AppImage (portable) or .deb for Debian/Ubuntu. Also available as .rpm.

If the AppImage won't start, install the WebKit runtime: sudo apt install libwebkit2gtk-4.1-0.

Download for Linux

No install? Run it in your browser

The web app is the whole thing — tools, files, voice, local WebGPU models and the in-browser Linux sandbox all work in a modern browser. Your data stays in the browser's local storage on your device.

Open the web app → Install guide

Good to know

Bring your own model

There's no bundled model and no key baked in. Point it at a local runtime or paste your own cloud key — you're never billed by us.

Automatic updates

The desktop app checks for new releases and updates itself, so you stay current without re-downloading by hand.

Open source

Apache-2.0 licensed. Read the code, build it yourself, or file an issue on GitHub.
