Features

Everything you plug a model into

You bring the model — local via Ollama, LM Studio or in-browser WebGPU, or a cloud model with your own key. HarnessStation gives it the tools, context and automation to actually do work.

Do real work

A chat becomes an agent the moment it can act on the world outside the text box.

Tools & files

Read and write files, run terminal commands, search the web and fetch pages — all confined to a working directory you choose.

Every tool call is shown as an inspectable card: what was called, with which arguments, and what came back.

Tools & the working directory →

A real browser

Give the model a browser it can navigate, read and click through — for research, forms and scraping that a plain fetch can't handle.

And the showstopper: a full Linux kernel boots client-side via WebAssembly, sharing a filesystem with the model's tools.

Browser & sandbox →

MCP servers

Connect hundreds of Model Context Protocol servers — local (stdio) or remote — to add tools for GitHub, databases, search and more.

Browse a built-in directory, and drop in an API key with a single field where a server needs one.

Connecting MCP →

Ground it in what matters

Give the model your knowledge and your memory, without handing your data to anyone.

Knowledge bases

Point it at your documents and it retrieves the relevant passages at answer time, with local or cloud embeddings — grounded answers, no fine-tuning.

Knowledge bases →

Memory

Durable facts carried across every chat — remembered automatically or on request, and stored as plain files you can read and edit.

How memory works →

Secrets vault

Store API keys and tokens the model can use but never see: it types a placeholder, the app swaps in the real value at run time and scrubs it back out.

The secrets vault →

Talk to it, and let it run

Voice in and out with no server, plus automation that keeps working while you're away.

Voice & avatars

Local speech-to-text and neural voices, barge-in so you can interrupt, wake words, and optional 3D VRM avatars — all on-device.

Talking to it →

Agents & workflows

Package instructions, tools and knowledge into a reusable agent, then chain agents and prompts into multi-step workflows with branching.

Agents →

Schedules & channels

Run an agent or workflow on a schedule and have it deliver the result to a chat, a webhook or Slack. Reach it from Telegram or Discord too.

Schedules →

More models, more ways

Run models locally, in the browser, or through three dozen cloud providers with your own key — and put several in one room.

Local & in-browser models

Download a GGUF and run it through tuned llama.cpp flags, connect Ollama or LM Studio, or run a small model on WebGPU right in the tab — no install at all.

Running local models →

Multi-agent chats

Put up to five models in a single conversation. Battle sends one prompt to each independently and shows the answers side by side; Collaborate gives them a shared transcript so they build on each other.

Each participant has its own reasoning effort and a thinking on/off switch, and can be backed by a saved agent.

Multi-agent chats →

Community library

Import skills, agents, workflows, schedules and templates others have shared — or publish your own, free. Everything is just JSON you can inspect first.

The community library →

Private by default, synced only if you ask

The whole app runs on your machine. If you want your chats and setup on another device, opt in to cloud sync: your data is encrypted with a key derived from your password before it leaves the device, so the server only ever stores ciphertext — and your API keys never sync at all.
