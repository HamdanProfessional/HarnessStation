What you plug a model into

A harness, not another chat box

You bring the model — free and local via Ollama, LM Studio or in-browser WebGPU, or a cloud model with your own key. HarnessStation gives it everything it needs to actually do work.

Tools & files

Read and write files, run commands, search the web, and drive a real browser — inside a working directory you control.

Voice

Talk to it. Local speech-to-text and neural voices, barge-in, and 3D avatars — no server required.

Automation

Package roles as reusable agents, chain steps into workflows, and run them on a schedule while you're away.

MCP & knowledge

Connect hundreds of MCP servers and ground answers in your own documents with local or cloud embeddings.

Local models

Download a GGUF and run it with tuned llama.cpp flags, or run a small model on WebGPU right in the tab.

Multi-agent chats

Put up to five models in one conversation — compare them side by side, or have them collaborate on parts of a task.

One app, two places

Nothing to install, if you don't want to

The desktop app and the web app are the same React tree — not a cut-down demo. Open a tab and you get a working agent workstation in seconds, with a real Linux kernel, real CPython and a persistent filesystem running inside the page. Nothing is uploaded; it all executes in your own browser.

Real Linux, client-side

A Linux kernel boots in WebAssembly (v86) and shares a workspace with the model's file tools. No server, no container, no install.

Real Python

CPython via Pyodide, so the model can actually run the code it writes — in the tab, on your machine.

A filesystem that persists

Files live in the Origin Private File System, sandboxed so a path can't escape into the app's own data. Close the tab and come back to it.

Private by design

Your keys and data stay on your machine

This isn't a marketing line — it's how the app is built. By default there's nothing to log into and nothing phoning home. Backup to the cloud is entirely opt-in and end-to-end encrypted, so even then the server only ever holds ciphertext it can't read.
