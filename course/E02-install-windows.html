Installing on Windows

Four clicks — one of which looks scarier than it is.

The whole flow

Four steps, start to finish

  • 1 — Download the installer
  • 2 — Run it
  • 3 — Get past the SmartScreen warning the one that looks alarming
  • 4 — Launch the app

Step 1 — Download

Get the Windows installer

From the releases page, download the .msi / .exe. No runtime to install alongside it.

Step 2 — Run it

Double-click to install

Run the file you just downloaded…

Step 3 — The warning everyone hits

“Windows protected your PC”

  • This is expected, not a problem
  • It appears because the app isn't code-signed yet
  • Signing is a paid certificate identifying the publisher — not a safety scan

Getting past it

More info → Run anyway

Click More info to reveal the button, then Run anyway. The install proceeds as normal.

No extra runtime

WebView2 is already there

The UI runs on WebView2, which is built into Windows 10 and 11. Nothing else to install.

Step 4 — Launch

First run

Open HarnessStation from the Start menu — the app window comes up. You're installed.

Gotcha / alternative

Don't want to run unsigned?

Build it yourself from source and audit it first — that's Episode 4.
