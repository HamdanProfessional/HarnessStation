Picking a voice

Four engines, one sensible default.

The four engines

Quality vs cost vs privacy

Kokoro  free · local · very good · English only
Cloud   best · per-character · OpenAI/ElevenLabs/Cartesia/Groq
Piper   free · local · lighter/faster · more synthetic
System  free · instant · flattest · offline for many languages
Auto    picks one for you

The default: Kokoro

Local, good, starts fast

  • One-time ~90 MB download
  • Speaks a sentence at a time — long replies start immediately

Best quality: Cloud

Add a key — with a safety net

Cloud voices sound best. If a request fails, the app falls back instead of going silent.

Gotcha

Local engines are English-only

  • Kokoro & Piper: English only
  • Other languages → a Cloud engine, or a System voice with that language installed
