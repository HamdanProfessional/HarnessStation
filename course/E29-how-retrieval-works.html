How retrieval works

Chunk, embed, search — and its real limits.

The pipeline

Chunk → embed → nearest-neighbor

split document into chunks
      ↓
embed each chunk
      ↓
question arrives → embed it too → find nearest chunks

Three limits

Structural, not accidental

  • Not exhaustive — nearest chunks, not all relevant ones
  • Chunk-boundary splitting can separate a fact from its context
  • Meaning-based, not keyword-based — usually right, sometimes not

Better-results checklist

Five habits that help

  • Use the documents' own vocabulary
  • Ask narrow questions, not broad ones
  • Ask it to say when something's absent
  • Split unrelated material into separate bases
  • Name bases descriptively

Gotcha

A scanned PDF is an image

No OCR is performed — it indexes silently and returns nothing useful. OCR it before adding.
