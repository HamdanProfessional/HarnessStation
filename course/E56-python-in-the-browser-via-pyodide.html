Python in the browser via Pyodide

Real CPython, compiled to WebAssembly, in the tab.

The problem

No system Python, no shell-out

Desktop shells out to python on PATH. The browser has no process to shell out to — so pyodide.ts brings CPython itself, as WASM.

Loaded on first use

Fetched from the CDN, not bundled

first python tool call → fetch pyodide.mjs from CDN
      → cached → every call after this is local

Same contract as desktop

python_run, unchanged from above

  • Run the tool's code, call the named function with the JSON args
  • Returns json.dumps of the result — identical shape to desktop
