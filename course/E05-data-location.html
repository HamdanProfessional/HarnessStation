Track A · Beginner · Episode 5

Where your data lives

One folder, plain files, no database.

One home for everything

The ~/.harnessx folder

~/.harnessx            # Windows: %USERPROFILE%\.harnessx

What's inside

A folder per thing

settings.json     # your settings (keys blanked — see next)
conversations/    # every chat, one file each
presets/  snapshots/  exports/
agent-memory/  avatars/
models/  engines/  # local model weights + runtimes
tmp/

No database

A chat is just a text file

Open one in conversations/: readable JSON you can back up, diff, or move with a plain copy.

The one exception

Your keys aren't here

  • API keys live in the OS credential store Windows Credential Manager · Linux Secret Service
  • So copying ~/.harnessx never leaks your keys

Gotcha

Don't edit while it's running

The app keeps chats in memory and rewrites them on save — hand-edits made while it's open get overwritten. Close it first.
