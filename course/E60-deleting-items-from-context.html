Deleting individual items from context

Surgical cleanup, one item at a time.

Three controls

Hover, then delete just that item

  • Reasoning block → Delete this thinking from context
  • Tool call → Delete this tool call from context
  • Tool response → Delete this tool response from context

The use case

Noisy steps, but a thread worth keeping

A long session accumulates wrong or noisy intermediate steps that poison context — but the conversation is otherwise worth keeping.

Why surgical wins

Better than starting over or compacting

  • Starting over — loses the whole thread
  • Full compaction — summarizes everything, even what was fine
  • Item deletion — removes just the bad steps

The payoff

Less noise, fewer tokens

Every deleted item is context the model no longer re-reads — a smaller, cheaper prompt on the next turn.

Gotcha

Disabled while a reply streams

Deletion applies only to settled history — not while a response is actively streaming.
