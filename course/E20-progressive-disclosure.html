Progressive disclosure

Ten servers, without flooding the model.

The problem

Tool definitions add up fast

N servers × M tools = a giant block of definitions on every request. Costly, and it degrades the model's choices.

The fix — four meta-tools

Discover, then call

mcp_servers   what's connected?
mcp_tools     what can this server do?
mcp_describe  details of one tool
mcp_call      run it

Live

The model narrows down itself

Ask for a capability → it walks mcp_servers → mcp_tools → mcp_call. Only what it needs enters the prompt.

The tradeoff

A couple of extra hops up front

  • One server → not worth it
  • Past ~two servers → clearly worth it
