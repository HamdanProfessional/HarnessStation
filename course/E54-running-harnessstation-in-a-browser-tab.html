Running HarnessStation in a browser tab

Same app, zero install, one clever seam.

Standing it up

npm run web:dev

$ npm run web:dev
→ http://localhost:5175

The seam

Five imports, one swap

Desktop talks to Rust through five @tauri-apps/* imports. The web build aliases each to a browser impl in web/shims/ — same src/ tree, no forked UI.

web/shims/

The shim table

core.ts    command dispatcher
fs.ts      OPFS
http.ts    native fetch — CORS applies
event.ts   local no-op bus
secret.ts  browser secret store

What doesn't run in a tab

Mixed content and native-only features

  • Local models via localhost — blocked as mixed content
  • stdio MCP servers, the device mesh, the native in-app browser
  • Each fails as an ordinary “not available” error, not a crash

Since then

WebGPU is the exception

Local models can now run in-tab too, on a WebGPU-capable GPU — the one exception to “local models don't run in the browser.”
