Memory — three scopes and the budget

What it remembers, where, and how much it can hold.

Three scopes

Chat · Project · Global

  • Chat — visible only in that one conversation
  • Project — shared across every chat in that project
  • Global — follows you everywhere

How facts get in

Passive extraction, or told directly

  • Passive — the app extracts facts as you talk (Settings › Memory)
  • Deliberate — you say “remember that…” and it saves it

Settings › Memory

List, delete, and Tidy

  • Facts listed by scope — delete any one directly
  • Tidy merges near-duplicate facts into one

The budget

20% default, 25% hard cap

default   20% of context window
max       25% — hard-capped, cannot be raised
→         smaller model = smaller share = less recall

Gotcha

Memory ≠ knowledge

  • A style preference — that is memory
  • A 200-page spec — that is knowledge, not memory
  • A document in memory can blow the whole budget on one file
