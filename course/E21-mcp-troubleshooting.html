MCP troubleshooting

Three failures, three fixes.

1 — Won't start

Test the command in a terminal

Run it directly to see the actual error — a bad command or a missing package, surfaced plainly.

2 — Connected, no tools

Disconnect, reconnect

Some servers publish tools only after init — a reconnect picks them up.

3 — Auth failures

Fix by transport

  • stdio — check the env token (typo / expired)
  • http — redo the OAuth sign-in for a fresh token
