Building from source

Optional — for auditing, or for developing on the app.

Prerequisites

Three things to install first

  • Node 18+
  • Rust via rustup
  • A C++ toolchain Windows: VS 2022 Build Tools + “Desktop development with C++”. Linux: build-essential

Step 1 — Dependencies

Install the front-end deps

$ npm install

Step 2 — Run it in dev

npm run tauri dev

$ npm run tauri dev
  • First build: hundreds of Rust crates, a few minutes
  • After that: incremental, and the UI hot-reloads

Step 3 — Package it

Build a real installer

$ npm run tauri build

Outputs the installer / binary for your OS — the same artifact the release ships.

Prove the build is sound

Tests & type-check

$ npm test          # the full unit suite
$ npx tsc --noEmit  # type-check, no output = clean
