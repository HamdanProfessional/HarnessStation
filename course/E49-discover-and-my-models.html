The Rust underneath

hw_info, streamed downloads, safe extraction

  • hw_info detects RAM, AVX2, and NVIDIA GPU via nvidia-smi
  • Downloads stream to .part, renamed only on success
  • Archives extracted in-process with path-traversal protection

Gotcha

“Will it fit” ≠ “will it work well”

It checks memory, not tool-calling reliability — re-run the E48 README test before trusting it.
