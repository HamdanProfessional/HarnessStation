The OPFS workspace and the coreutils shell

A sandboxed filesystem, and a shell to drive it.

vfs.ts

A workspace with no real disk underneath

Desktop points file tools at a real folder. The browser has none — vfs.ts gives the model a persistent workspace inside OPFS instead.

The sandbox

A path can't escape the workspace

  • Every tool path resolves under one workspace root
  • .. segments that would climb out are clamped, not followed

shell.ts

A coreutils subset over the same workspace

ls · cat · echo · grep · head · tail · mkdir · rm · cd
      | pipes    > >> redirection    && ; sequencing

The demo

The default browser-build terminal

$ ls | grep .txt && cat notes.txt
$ cd data && echo done > status.txt

Gotcha

It's a subset, not real bash

  • An unknown command returns 127 — it won't silently pretend to run it
  • Reach for the file tools or Python for anything outside this list
