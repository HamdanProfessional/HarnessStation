A free local model

Zero cost, fully private — with Ollama.

Step 1 — Get Ollama going

Pull a model

$ ollama pull qwen3
$ ollama serve        # usually already running

Step 2 — Point the app at it

Settings › Providers

The Ollama (local) provider is built in and auto-detects the server at localhost:11434/v1.

If it isn't auto-detected

Add it by hand

  • Base URL http://localhost:11434/v1
  • API key — leave blank a local server needs none

Step 3 — List your models

Save → Fetch models

The app queries Ollama and lists what's installed — qwen3 should appear. You now have a free model wired in.

Gotcha / alternative

Prefer a GUI? LM Studio

  • Same setup, graphical
  • You must start its server from the Developer tab first
