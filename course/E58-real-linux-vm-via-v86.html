A real Linux VM in the tab, via v86

Not a simulation — a booted kernel, running in WebAssembly.

Turning it on

Settings → the real-Linux toggle

  • Off by default — an explicit opt-in
  • Once on, run_command routes to the VM, not the coreutils shim

What's booting

Buildroot + BusyBox, under v86

emulator  v86 — x86 → WebAssembly, open source
guest     Buildroot / BusyBox
link      serial console (no GUI)

Why v86, not CheerpX

BSD-licensed beats billed

  • v86 — BSD-licensed, free for commercial use
  • CheerpX — faster, but proprietary and would bill

The 9p bridge

One workspace, two vantage points

guest mount   /mnt
model workspace  /mnt/workspace   ← same files, both sides

The costs

What it actually costs you

  • ~10MB one-time kernel download
  • A few seconds to boot
  • Emulated = slower than native
  • Headless, serial-only — no GUI

Gotcha

A demo, not a daily driver

Experimental — treat it as “look what's possible.” ~40s boot, 30s per-command timeout.
