Scheduling an agent
or workflow

Guardrails first, then let it run unattended.

Where it lives

Automation › Schedules › New

  • What to run — an agent or a workflow
  • Interval presets, or a cron expression
  • Where results land — new chat, append, or notification

Hard prerequisite

Settings › Usage — spend cap first

  • Set the cap before the first scheduled run, not after

Settings › General

Keep running in the tray

  • Lets schedules fire with the window closed
  • A missed run does not fire retroactively — it's just skipped

Worked example

The morning briefing

instruction  if nothing needs attention,
           say plainly “nothing needs
           you today”

Gotcha

Report, don't act unreviewed

  • Good candidates report — draft, summarize, notify
  • Poor candidates act — send mail, post, commit — with nobody watching
