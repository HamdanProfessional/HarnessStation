Local vs cloud, exactly

What runs here, and what leaves.

On your machine

Everything with hands

  • The interface, and all storage
  • Every file / terminal action and tool run
  • Whisper transcription, local speech, the browser panel

On the provider (cloud model)

The model, and nothing else

  • Receives the assembled prompt → returns text
  • Never touches your files — the app does that locally

What leaves your machine

Five setups

local model, no tools          nothing leaves
local model + local embeddings nothing leaves
cloud model                    prompts + shown snippets
cloud embeddings               your indexed text
cloud voice                    your spoken words / replies

Gotcha — the surprising row

Cloud embeddings upload everything

  • Building the index sends every document, not just retrieved passages
  • Sensitive knowledge base? Use local embeddings
