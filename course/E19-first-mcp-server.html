What MCP is

A standard plug for tools

Model Context Protocol: an open standard so any tool provider ships a server, and the app connects. Hundreds exist already.

Add one

Automation › MCP Servers › Add

  • stdio — a local command the app launches
  • http — a remote server over the network

stdio example

A local npx server

command  npx -y @modelcontextprotocol/server-github
env      GITHUB_TOKEN = ghp_…

http example

A remote server + OAuth

  • Add the URL → sign in → authorize in the browser
  • The token lands in the OS credential store

Gotcha

Run npx servers once in a terminal first

The first run downloads the package and can time out inside the app. Pre-run it in a terminal, then connect.
