Bring your own
cloud key

Add a paid provider — and know where the key goes.

Add it

Settings › Providers › Add provider

  • Name — anything you like
  • Base URL — e.g. https://api.openai.com/v1
  • API key — from the provider's dashboard

Common providers

Just a different base URL

OpenAI      https://api.openai.com/v1
Anthropic   https://api.anthropic.com
OpenRouter  https://openrouter.ai/api/v1
Groq        https://api.groq.com/openai/v1
Together    https://api.together.xyz/v1

Where the key goes

Into the OS keychain, nowhere else

  • Stored in the OS credential store, not settings.json
  • Sent only to that provider — never through us, never into a chat

Gotcha

Why Anthropic is listed separately

It's a native integration (the /v1/messages API), not OpenAI-compatible. Pick “Anthropic” as the kind — nothing else to do.
