## Slide 1 · ~7s

**Narration:** Module 13 is the device mesh — letting two machines you own work together. This episode: turn it on, find each other, and pair them with a real proof-of-knowledge handshake.

## Slide 2 · ~10s

**Narration:** Settings, Devices. Give this machine a name, hit Turn on, and optionally set it to start with the app so it's always reachable. That's the whole setup on one side of the link.

**On screen / action:** SWITCH TO APP: Settings › Devices. Name the machine, toggle Turn on.

## Slide 3 · ~9s

**Narration:** On the same LAN, machines with the mesh on find each other automatically. If discovery doesn't show one — different subnet, different network — you can always add it directly by address instead.

**On screen / action:** APP: show the discovered-devices list, then add a device by address.

## Slide 4 · ~14s

**Narration:** Pairing: on the target machine, click Show pairing code — it's valid five minutes and single-use. On the initiator, enter that code plus the target's address. Behind the scenes it's a proof-of-knowledge handshake, so neither the short code nor the long-lived token it produces ever crosses the network in the clear.

**On screen / action:** SWITCH TO APP, target machine: Show pairing code. Then on the initiator: enter code + address.

## Slide 5 · ~9s

**Narration:** Once that handshake completes, the two machines have a long-lived trust relationship — you don't re-pair every session. What that trust does and doesn't grant is next episode's whole subject.

## Slide 6 · ~16s

**Narration:** Say this one loud and clear: the mesh traffic itself is not encrypted yet. The handshake protects your credentials and blocks replay attacks, but everything after that — prompts, tool output, retrieved documents — travels in plaintext. That's fine on a home LAN you trust. Across the open internet, only inside a VPN or tunnel, Tailscale, WireGuard, SSH — never a forwarded port.

## Slide 7 · ~6s

**Narration:** Two machines are paired. Next: exactly what that pairing lets one machine do on the other — and the hard boundaries that hold no matter what you switch on.
