## Slide 2 · ~11s

**Narration:** You need three things installed first: Node, version eighteen or newer; Rust, through rustup; and a C++ toolchain — that's the Visual Studio 2022 Build Tools with the C++ workload on Windows, or build-essential on Linux. The C++ part trips people up, so don't skip it.

## Slide 3 · ~9s

**Narration:** Clone the repo, then install the JavaScript dependencies with npm install. This pulls the front-end packages; the Rust crates come on the first build.

**On screen / action:** SWITCH TO TERMINAL: in the repo, run npm install and let it finish.

## Slide 4 · ~13s

**Narration:** Now run the app in dev mode with npm run tauri dev. Fair warning: the very first build compiles several hundred Rust crates and takes a few minutes — don't panic when it sits there. After that it's incremental and fast, and the front end hot-reloads as you edit.

**On screen / action:** TERMINAL: run npm run tauri dev. WAIT — first Rust build is minutes. Cut to the app window opening; then edit a file to show hot-reload.

## Slide 5 · ~8s

**Narration:** When you want a real installer — the same kind we downloaded in the earlier episodes — run npm run tauri build. It produces the packaged app for your platform.

**On screen / action:** TERMINAL: run npm run tauri build; then show the installer/binary it produced in src-tauri/target/release.

## Slide 6 · ~11s

**Narration:** Two commands worth knowing, and a nice credibility check: npm test runs the project's real test suite — hundreds of tests — and npx tsc --noEmit type-checks the whole thing. If both are green, your build is sound. We'll lean on these in the developer track.

**On screen / action:** TERMINAL: run npm test (show the passing count) and npx tsc --noEmit (clean).
