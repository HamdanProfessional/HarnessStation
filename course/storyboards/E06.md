# E06 · Connecting a free local model (Ollama)

## Slide 1 · ~7s

**Narration:** Let's get a model talking to the app that costs nothing — a local model through Ollama. This is the perfect way to try everything in the course before you spend a cent.

## Slide 2 · ~10s

**Narration:** First, install Ollama from its site. Then pull a model — I'll use qwen3 here — and make sure Ollama is running in the background. On most systems it starts serving automatically after install.

**On screen / action:** SWITCH TO TERMINAL: run the pull, then confirm ollama is serving (ollama serve / it runs as a service).

## Slide 3 · ~11s

**Narration:** Now open the app, go to Settings, then Providers. HarnessStation ships with an Ollama provider already listed, and it auto-detects the server running on localhost port eleven-four-three-four. If it's found, you'll see it right there.

**On screen / action:** SWITCH TO APP: open Settings › Providers. Point at the Ollama (local) provider auto-detected on localhost:11434/v1.

## Slide 4 · ~10s

**Narration:** If for some reason it isn't detected, add it by hand: the base URL is http://localhost:11434/v1, and you leave the API key blank — a local server needs no key.

**On screen / action:** APP: if needed, show adding it by hand — base URL field + leaving the API key blank.

## Slide 5 · ~9s

**Narration:** Press Save, then hit Fetch models. The app asks Ollama what you've got installed and fills in the list — you should see qwen3, the one we just pulled. That's it: a working, free model.

**On screen / action:** APP: click Save, then Fetch models — show the model list populate with qwen3.

## Slide 6 · ~11s

**Narration:** One aside. If you prefer a graphical app, LM Studio is a great alternative. Same idea — but its server isn't on by default: you start it manually from the Developer tab. Once it's serving, you connect it exactly the same way.

**On screen / action:** OPTIONAL: show LM Studio — its Developer tab, and the 'Start server' toggle.
