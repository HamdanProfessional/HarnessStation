**Narration:** Before you add a single document, pick an embedding model in Settings, Providers, Embeddings. This choice matters more than it looks — it decides how every document gets indexed, and you'll see why shortly.

## Slide 3 · ~13s

**Narration:** Two real options. Local, with Ollama's nomic-embed-text — free, and your documents never leave the machine. Cloud, with text-embedding-3-small — cheap per document, but every file you index gets uploaded to the provider to be embedded. Pick based on how sensitive the documents are.

**On screen / action:** APP: Automation › Knowledge › New knowledge base. Name it, then add a few PDFs and Markdown files.

## Slide 5 · ~12s

**Narration:** Attach the base to a chat and ask a question that's only answered inside one of your documents. No explicit search instruction needed — retrieval happens automatically before the model even starts composing a reply, and the answer comes back grounded in your text.

## Slide 6 · ~12s

**Narration:** The gotcha: changing the embedding model invalidates every index built with the old one. And re-indexing is not incremental — it redoes the whole base from scratch. Pick your embedding model deliberately before you import a large collection, because switching later is expensive.
