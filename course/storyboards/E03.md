## Slide 1 · ~6s

**Narration:** Let's install HarnessStation on Linux. Two ways to do it, and one common launch failure that has a one-line fix.

## Slide 2 · ~8s

**Narration:** You've got two options. The AppImage is a single portable file that runs anywhere — nothing to install. Or, on Debian and Ubuntu, install the dot-deb package system-wide. Pick whichever you prefer.

## Slide 3 · ~9s

**Narration:** For the AppImage, mark it executable with chmod plus x, then run it. That's it — the app launches straight from the file.

**On screen / action:** SWITCH TO TERMINAL: cd to the download, run the two commands, then the app window opens.

## Slide 4 · ~8s

**Narration:** Prefer a proper install? On Debian or Ubuntu, install the dot-deb with dpkg, and it'll show up in your application menu like any other program.

**On screen / action:** TERMINAL: run the dpkg install (show sudo password prompt), then launch from the app menu.

## Slide 5 · ~14s

**Narration:** Now the gotcha. On a fresh system the AppImage sometimes just… doesn't start — no window, no obvious error. Nearly always it's a missing WebKit library. Install these two packages with apt, run it again, and it comes up. This is the single most common Linux issue, so keep this command handy.

**On screen / action:** OPTIONAL: reproduce the silent-fail (run AppImage, nothing happens), then run the apt fix, then it launches.

## Slide 6 · ~11s

**Narration:** One optional extra. If you want the app to speak using your system's built-in voices, install espeak-ng and speech-dispatcher. This is only for the system voice — the app's own neural voice, Kokoro, runs locally and needs none of this. So it's genuinely optional; skip it for now if you're not sure.
