## Slide 5 · ~14s

**Narration:** You'll see this blue box: “Windows protected your PC.” Don't panic — this is expected. It shows up because the app isn't code-signed yet. Code signing is a paid certificate that tells Windows who published the software; this project doesn't have one yet, so Windows shows the warning for any unknown publisher. It is not a sign that anything is wrong with the download.

**On screen / action:** SCREEN: let the blue 'Windows protected your PC' SmartScreen dialog appear on camera. Hover it.
