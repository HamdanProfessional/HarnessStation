## Slide 3 · ~12s

**Narration:** The one extra requirement: Python tools need Python available on your system PATH on the desktop app. If a Python tool silently does nothing, that's the first thing to check — the app couldn't find Python to run it. JavaScript tools have no such dependency; they run in the app itself.

## Slide 4 · ~11s

**Narration:** One convenience, with a caveat. The app tries to auto-detect the parameter schema from your function's signature and docstring, which saves you writing JSON by hand. But check it — auto-detection isn't perfect, and a wrong schema means the model calls your tool with the wrong shape of arguments. A quick look saves a confusing failure.
