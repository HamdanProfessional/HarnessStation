Track B · Intermediate · Episode 46 · Module 11

Chats — folders, snapshots, branching, compaction

Managing history once you actually have some.

Right-click menu

Pin, rename, folder, duplicate, export, delete

  • Pin · rename (or auto-title) · move to folder · duplicate
  • Export as Markdown or JSON
  • Delete — no undo

Snapshots

A safety net before risky tool work

  • Snapshot before a task that edits files or runs commands
  • Restore rolls back — the chat keeps its identity

Branch vs. edit

Fork it, or change it in place

  • Branch from a message — forks a new chat, original stays intact
  • Edit a message — changes history in place, same chat

Compact

Fold the old, keep the recent

  • The banner marks where older turns became a summary
  • Auto-compact triggers on its own past a threshold you set

Gotcha

Compaction loses detail on purpose

Anything you want verbatim later belongs in an export or memory — not left to survive a compaction.
