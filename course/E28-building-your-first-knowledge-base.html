Local vs cloud

Two real options

Local — nomic-embed-text

Runs through Ollama. Free, and fully private — nothing leaves the machine.

Cloud — text-embedding-3-small

Cheap per document, but every file is uploaded to the provider to be embedded.

Build it

Automation › Knowledge › New

add  a few PDFs + Markdown files
# chunked and embedded automatically

Use it

Attach to a chat, just ask

  • Retrieval runs automatically — no “search” instruction needed
  • The answer is grounded in your own documents

Gotcha

Changing embeddings invalidates the index

Re-indexing is not incremental — it rebuilds the whole base. Choose the model before a big import.
