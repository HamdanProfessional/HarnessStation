The loop

Assemble → send → reply → maybe loop

assemble prompt + tool list
      ↓
send to the model
      ↓
reply?  ── text ──▶ stop
      └── tool call ──▶ run it ──▶ add result ──▶ loop

Why agent tasks cost more

Each lap is its own billed request

  • 8 tool calls ≈ 9 requests, not one
  • Being specific keeps the loop short — and cheaper

What's in the prompt, in order

Nine layers, your message last

1 global instructions      6 skill index
2 project instructions     7 tool definitions
3 chat instructions        8 conversation history
4 recalled memory          9 your message (last)
5 retrieved knowledge

Why the loop stops

Five ways a turn ends

  • It answered
  • It hit the step limit
  • It caught itself repeating
  • You stopped it, or a spend cap was reached
  • It errored

Gotcha

Instructions layer — they don't replace

  • A chat prompt doesn't override the global one — both apply
  • An “ignored” instruction is usually another layer contradicting it
