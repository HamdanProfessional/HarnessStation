Backing up and moving to a new machine

Compress, move, restore — and re-pair when you're there.

Step one — compress

tar.gz on Linux, Compress-Archive on Windows

Linux    tar -czf backup.tar.gz ~/.harnessx
Windows  Compress-Archive ~/.harnessx backup.zip

Step two — restore

Extract, then re-enter your keys

  • Move the archive, extract it into place
  • Keys live in the OS credential store only — re-enter them by hand

Why it's this simple

One folder is the whole app

No database server, no cloud account holding your history — one folder is a complete backup.

Gotcha

Device identity doesn't travel with the copy

A copied install keeps the old device id — running both at once confuses the mesh. Re-pair from the new machine.
