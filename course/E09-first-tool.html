Track A · Beginner · Episode 9

Giving it a tool

The single most important “aha” of the series.

Step 1 — Switch on Files

The tools panel, right of the chat

Toggle on Files. The model can now read and write — within a boundary you set.

Step 2 — Set the boundary

The working directory is a hard wall

  • The model can only reach files inside this folder
  • Nothing above it, nothing elsewhere on disk

Step 3 — Ask it to act

“Read the README and tell me
what this project does.”

The aha

Call → read → respond, in the open

  • The tool-call card shows the call, its arguments, and the result
  • All inspectable — nothing hidden behind the answer

Gotcha

If it won't call the tool…

  • Small local models are unreliable at tool calls — regardless of their model card
  • Test the same prompt on a bigger model before assuming it's broken
