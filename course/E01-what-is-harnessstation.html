What HarnessStation
actually is

Setting expectations before you install a thing.

The one-line pitch

“A desktop app for running
AI models as agents.”

The keyword is agents — a model that reads your files, runs commands, browses the web and remembers, not just one that answers.

It's a harness, not a model

You bring the model.

Local & free

Run models on your own hardware via Ollama or LM Studio. No key, no bill, fully offline.

Cloud & your key

Point it at OpenAI, Anthropic, Groq, OpenRouter… with your own API key. You pay them directly.

What HarnessStation gives the model

The capabilities you plug a model into

  • Conversations — typed or spoken, saved as plain readable files
  • Tools — read files, run commands, search the web, call APIs
  • Knowledge & memory — your documents, and facts it recalls across chats
  • Browser control, voice, automation, MCP servers, a device mesh

What it deliberately does not do

Private by design

  • No API keys ship with the app you add your own; they go to the OS credential store
  • No account, no sign-up nothing to register, nothing to log into
  • No telemetry it isn't phoning anything home
  • No cloud sync your chats and data stay on your machine

The series roadmap

Where we're headed

Advanced → Developer

A straight word

It's early software — and honest about it
