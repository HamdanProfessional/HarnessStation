Installing on Linux

AppImage or .deb — plus the fix for a stubborn first launch.

Two ways in

AppImage or .deb

AppImage

One portable file. Make it executable and run it — no system install, works across distros.

.deb package

For Debian / Ubuntu. Installs system-wide with your package manager.

Option A — AppImage

Make it executable, run it

$ chmod +x HarnessStation*.AppImage
$ ./HarnessStation*.AppImage

Option B — .deb

Install with dpkg

$ sudo dpkg -i HarnessStation*.deb

Then launch it from your applications menu.

The one common failure

“It won't start” → missing WebKit

$ sudo apt install libwebkit2gtk-4.1-0 libjavascriptcoregtk-4.1-0
  • Symptom: AppImage runs but no window appears
  • Fix: install the two libraries above, then relaunch

Optional — system speech

Want system voices? Two more packages

$ sudo apt install espeak-ng speech-dispatcher
  • Only needed for the system voice
  • The built-in neural voice (Kokoro) is local and needs none of this
