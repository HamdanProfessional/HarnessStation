Track A · Beginner · Episode 14 · Module 4

Working with a codebase

The first full, real use case.

Set up

Point it at a real repo

Working directory → the project folder. Files tools on. That folder is the whole world the agent can see.

Understand it

Ask a scoped question

  • “Explain this whole repo” — wastes reads
  • “How does auth work? Start from the login route.”

Review a change

“What changed in the last commit —
anything risky?”

Make a small edit

One file, one change, visible

The edit appears as a tool-call card — inspect the diff before you trust it.

For multi-file work

Plan first, then execute

  • “Plan the change across these files, then wait.”
  • Correcting a plan is cheap; correcting five bad edits isn't

Gotcha

Vague requests = wasted exploration

“Fix the bug” makes it read half the repo guessing. Name the file, the function, the symptom.
