Touring src-tauri/src, command by command.

The boundary

#[tauri::command] is the seam

frontend: invoke("fs_read", { base, path })
      ↓
lib.rs: generate_handler![local::fs_read, …]
      ↓
local.rs: #[tauri::command] pub fn fs_read(...)

The pattern

The signature is the contract

  • No separate API spec — the Rust function signature is the source of truth
  • A mismatched invoke call fails at build time on the Rust side, or at runtime with a clear Tauri error

Gotcha

Only JSON-serializable data crosses

  • Arguments and return types need Serialize / Deserialize
  • File handles, threads, raw pointers stay on the Rust side behind a State
