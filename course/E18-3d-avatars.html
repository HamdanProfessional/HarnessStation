3D avatars

A character on screen — VRM and MMD.

Turn it on

Settings › Voice › On-screen character

Swap the orb for a VRM — a 3D character that animates while it speaks.

Getting a model

Import a VRM

  • VRoid Hub, or the built-in Open Source Avatars (CC0) list
  • Pick one → Import → it lands in your avatars folder

MMD models

Import .pmx as a .zip

MMD needs its texture folder alongside the model, so it's imported as a zip of both.

Licensing — don't skip this

Check before you publish

  • VRoid Hub models: per-creator terms (commercial / modify / corporate use)
  • Safe defaults: CC0 sources, or your own VRoid Studio character

Gotchas

Two things that aren't bugs

  • Mouth follows speech volume, not phonemes — approximate by design
  • It's GPU work — use the orb on battery / integrated graphics
