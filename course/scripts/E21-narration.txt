# Slide 1
A short, practical one to close the MCP module: the three things that actually go wrong when you connect a server, and how to fix each one fast.

# Slide 2
One: the server won't start at all. Almost always the command is wrong, or the package didn't download. Run the exact command in a real terminal — you'll see the real error there, where it isn't swallowed by the app.

# Slide 3
Two: it connects, but lists no tools. Some servers only expose their tools after they've finished initializing. The fix is almost silly but it works: disconnect and reconnect. The second connection catches the tools the first one missed.

# Slide 4
Three: authentication failures. For a stdio server, check the env token you set — a typo or an expired token is the usual culprit. For an http server, just redo the OAuth sign-in; tokens expire, and re-authorizing gets a fresh one. Two different fixes for the two transports.
