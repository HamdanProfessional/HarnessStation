# Slide 1
The in-app browser gives a clean session. This episode is for the opposite case — using a Chrome session you're already signed into, via the browser extension.

# Slide 2
Open chrome colon slash slash extensions, turn on Developer mode in the top right, click Load unpacked, and select the extension folder from this repo. It appears in your toolbar, and the agent can now drive that actual Chrome window.

# Slide 3
When to reach for this instead of the in-app browser: a login already established elsewhere — your email, a dashboard you're signed into — versus a clean, disposable session where you'd rather the agent start from nothing. Established login, use the extension; clean slate, use the in-app browser.

# Slide 4
This is also where tab tools live — they only exist here, not in the in-app browser: open_new_tab, list_tabs, change_tab, and close_tab. Real Chrome, real tabs.

# Slide 5
And unlike the in-app browser, this one really can take screenshots — take_screenshot and read_screenshot both work here, since it's a genuine Chrome window the extension can capture.

# Slide 6
The gotcha, and it matters: a signed-in session is delegated access. If you're signed into your bank, your email, your work systems in that browser, the model can act on any of them — not just the page you pointed it at. Treat the decision to hand it your session with the same care as handing someone your unlocked laptop.
