# Slide 1
Everyone asks: what actually leaves my machine? Let's make the local-versus-cloud boundary concrete instead of hand-wavy — because with an agent, it matters.

# Slide 2
On your machine: the whole interface, all file and terminal work, every tool execution, Whisper transcription, local speech synthesis, the browser panel, and all your storage. Everything with hands — anything that touches your files or your system — happens locally, always.

# Slide 3
On the provider, if you use a cloud model: the model, and only the model. It receives the assembled prompt and returns text. It never touches your files directly — when the agent reads a file, that happens on your machine, and only what the model needs to see is put into the prompt.

# Slide 4
Here's the same question across five real setups. A local model with no tools: nothing leaves. Local model with local embeddings: still nothing. A cloud model: your prompts and the file snippets it's shown leave. Cloud embeddings, and cloud voice: those leave too. Match your setup to the row you're comfortable with.

# Slide 5
And the row that surprises everyone, worth its own beat: cloud embeddings upload every document in a knowledge base to build the index — not just the passages that get retrieved. If a knowledge base is sensitive, use local embeddings. This is the single most misunderstood part of the privacy picture.
