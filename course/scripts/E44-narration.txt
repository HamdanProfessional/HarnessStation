# Slide 1
One reference episode covering every settings panel, so every later video can just say “see E44” instead of re-explaining. Worth bookmarking.

# Slide 2
Eight panels total: General, Providers, Media models, Voice, Memory, Devices, Usage, and Data & updates. We have touched most of these already — this is the map that ties them together.

# Slide 3
The search box at the top matches on what a setting does, not what it is called. Type “interrupt” and it finds barge-in, because that is the behavior, even though the word never appears in its label.

# Slide 4
Every panel uses the same draft-and-save model. Changes show an unsaved marker until you press Ctrl+S. Navigate away with unsaved changes and it confirms before discarding them — nothing is written until you tell it to.

# Slide 5
If you only change a handful of settings, make it these: spend caps, the voice engine, speech rewrite, auto-compact, the embedding model, background mode, and how much of the context window memory is allowed to use. Every one of them has come up already in this series for a reason.

# Slide 6
A few things people go looking for and will not find: a per-tool default model, cloud sync, and a memory share above the twenty-five percent ceiling. Each is a deliberate absence, not a missing feature — simplicity, no account to sync to, and protecting the context window on purpose.

# Slide 7
One update worth flagging: new chats now enable the built-in tools by default, rather than starting empty. That is a starting point, not a standing “enable everything forever” switch — you still trim it down per chat, the same habit from Module 7 about fewer tools choosing better.
