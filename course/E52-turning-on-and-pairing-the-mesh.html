Turning on and pairing the mesh

Two of your own machines, one trusted link.

Settings › Devices

Name it, turn it on

  • Name the machine → Turn on
  • Optional: start with the app

Finding each other

Auto-discovery, or add by address

  • LAN auto-discovery — same network, no setup
  • Add by address — works anywhere you can reach it

Pairing

A code, once, five minutes

  • Target: Show pairing code — 5 min, single-use
  • Initiator: enter code + address
  • Proof-of-knowledge handshake — code and token never cross the wire in the clear

After pairing

A long-lived, trusted link

No re-pairing each session — the token persists until you revoke it.

Gotcha

Mesh traffic is plaintext, not the handshake

  • The handshake protects credentials and blocks replay
  • Everything after — prompts, tool output, documents — is plaintext
  • Over the internet: only inside a VPN/tunnel, never a forwarded port
