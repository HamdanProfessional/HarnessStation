Privacy and security checklist before showing anyone

Every privacy point from the series, in one place.

What leaves the machine (from E12)

One table, restated

local model / embeddings   never leaves
cloud model call          prompt + context → provider
everything else          stays local by default

Be careful with

Five things that widen the blast radius

  • Terminal tool reach
  • Browser session delegation
  • Unattended schedules
  • The mesh's plaintext transport
  • Passive memory accumulation

Building private-by-default

Five switches, nothing needs to leave

  • Local model + local embeddings
  • Kokoro / Piper for speech, Whisper for transcription
  • Mesh off, or LAN-only

Reviewing after the fact

Tool-call cards, or grep the logs

grep -r "run_command" ~/.harnessx/conversations/

Sharing safely

The risk is your code, not your keys

  • An export never contains your keys
  • It contains everything the model read — read before sharing
