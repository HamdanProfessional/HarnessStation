Extending a view

A small, real feature, added to an existing panel.

The target

NotificationBell.tsx — small on purpose

const { history, unread, clearUnread, clearHistory } = useToast();
      // same shape as store.ts, scoped to just toasts

The feature

Mute one notification kind, persistently

Needs a setting that survives a restart — not just local component state.

Where the setting lives

store.ts settings, not local state

settings.mutedToastKinds: string[]   // new field
updateSettings({ mutedToastKinds: [...current, "info"] })

Enforcing it

One check inside toast.ts's push()

push(kind, message) {
  const muted = useStore.getState().settings.mutedToastKinds ?? [];
  if (muted.includes(kind)) return;
  set(s => ({ history: [...], unread: s.unread + 1 }));
}

The UI hook

A toggle inside the existing dropdown

<button onClick={() => updateSettings({
  mutedToastKinds: toggle(settings.mutedToastKinds, "info")
})}>Mute info</button>

Verify end to end

Mute it, restart, confirm it held

The whole point of putting it in store.ts instead of local state.
